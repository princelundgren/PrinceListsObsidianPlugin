A vault for trying PrinceLists. Install Tasks and Kanban too to see the Dashboard's query and the Garden board drawn.

- **Lists** are ordinary notes with `princelists: true` in their properties. Open one and it shows as a todo list.
- [[Groceries]], [[To do]], [[Inbox]] and [[Gift ideas]] sit in the root. More lists are in Home, Work, Health, Recipes, Travel, Media and Projects.
- [[Dashboard]] embeds lists with `princelists` code blocks, beside a Tasks query. [[Kickoff meeting]] embeds the project it started, and [[Weekend projects]] a shopping list.
- [[Garden board]] is a Kanban board, which PrinceLists leaves alone.
- Run **Open schedule** from the command palette to see every item with a day.
